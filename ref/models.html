(batch_size, seq_len - 1, hidden_dim) Right limits of [t_0, …, t_{N-1}, t_N] of shape: (batch_size, seq_len, 4 * hidden_dim) We need the right limit of t_N to sample continuation.

class easy_tpp.model.WSMTHP(model_config)

Bases: BaseModel

THP encoder trained with Weighted Score Matching (WSM).

The class name WSMTHP must match the model_id field in the YAML config.

YAML model_config parameters

Standard (top-level):

hidden_size int Transformer embedding / model dimension. num_layers int Number of Transformer encoder layers. num_heads int Number of attention heads. dropout_rate float Dropout probability.

WSM-specific (under model_specs):

d_inner int FFN inner dimension (default: hidden_size * 2). CE_coef float Weight for the mark cross-entropy term (default: 10.0). h_type str Weight function selector; currently only

'two_side_op' is supported (default).

T_mode str How to obtain the observation window end T:

'manual', 'train_global', or 'batch'.

max_observed_time float Observation window end T used when T_mode is

'manual'. When omitted under 'batch', T = max(time_seqs) inside each batch.
